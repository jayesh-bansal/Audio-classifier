# Messy Mashup - Music Genre Classification

## Project Overview
Robust music genre classification under realistic and noisy mixing conditions. The task is to predict the correct genre label for noisy mashups created by mixing instrument stems from different songs of the same genre, with added environmental noise.

## Dataset
- **genres_stems/** - 10 genres x 100 songs x 4 stems (drums, vocals, bass, others)
- **ESC-50-master/** - 2000 environmental noise clips for augmentation
- **mashups/** - 3020 unlabeled test mashups
- **Evaluation Metric:** Macro F1 Score

## Models
| # | Model | Type | Description |
|---|---|---|---|
| 1 | XGBoost | Classical ML | Handcrafted features (MFCC, chroma, spectral) |
| 2 | CNN | From Scratch | 4-block CNN on mel spectrograms |
| 3 | CRNN | From Scratch | CNN + Bidirectional GRU |
| 4 | AST | Pretrained | Audio Spectrogram Transformer (fine-tuned) |

Final predictions use a weighted ensemble of all models.

## Approach
1. **Data Augmentation:** Synthetic mashups generated by mixing stems from different songs of the same genre with tempo shifts and ESC-50 noise injection
2. **Feature Extraction:** Log-mel spectrograms (CNN/CRNN/AST) + handcrafted features (XGBoost)
3. **Training:** K-fold cross-validation with early stopping, SpecAugment, label smoothing
4. **Inference:** Weighted ensemble of all models
